# Patchdeck 0.6.2

## Fixed and improved

- Clearer update controls: status labels are read-only, with separate Install update
  buttons and a prominent bulk action. Installed and available versions appear first.
- A stable MQTT switch label, clearer grouped settings, visible save confirmations,
  stronger input boundaries, and distinct destructive styling.
- Inline validation for required fields, service IDs, numeric ranges, and URLs.
  Invalid settings are not sent to the server.
- Undo for removed service configurations, including multiple removals, retryable
  failures, conflict checks, and keyboard focus restoration. Undo remains available
  while the settings page stays open; removing a configuration does not stop its container.
- Existing-service autosave preserves hidden metadata and finishes before deletion,
  preventing a delayed save from recreating a removed service.
- Queued services show their position without an active progress bar. Running progress
  includes the service name and current phase.
- System typography, touch feedback, safe-area spacing, theme-aware browser chrome,
  keyboard navigation, and layouts that reflow with enlarged text.

## Verification

- 73 Python tests passed; Ruff, Mypy, locked dependencies, and JavaScript syntax checks passed.
- 32 browser layout checks passed across English/German, light/dark, both pages,
  and four viewport widths. Narrow layouts also passed at 200% root text size.
- Eight Axe scans reported no detected WCAG A/AA violations. Browser interaction
  checks cover validation, autosave/delete ordering, full undo, retry, conflicts,
  focus restoration, and update progress.
- Wheel, source archive, and the local release image are built and checked as part
  of the release process. Container images use the existing multi-architecture workflow.

Physical-device and assistive-technology checks remain open; automated checks do
not establish complete HIG or accessibility conformance. See the [UI review](../UI_REVIEW.md)
for findings, source references, reproducible browser checks, and remaining checks.
