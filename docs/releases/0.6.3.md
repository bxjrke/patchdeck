# Patchdeck 0.6.3

## Fixed

- Browser upgrades could reuse cached language dictionaries and the SVG icon sprite
  from an older release, even though the page, JavaScript, and stylesheet were new.
  This could expose labels such as `settingsIntro`, `enableMqtt`, and `mqttHelp`
  and leave the back button without its arrow.
- Dictionaries and the SVG sprite now use the page's asset version, matching the
  JavaScript and CSS. Dictionaries are explicitly revalidated, static responses
  require cache revalidation, and HTML pages are not stored.
- If an individual static label has no translation, its readable fallback copy is
  preserved instead of replacing it with an internal translation key.

## Verification

- The upgrade regression was reproduced using a genuinely fresh browser cache entry
  containing legacy dictionaries and a sprite without the back-arrow symbol.
- The same warm-cache upgrade passes with the fix in Chromium and WebKit, including
  German settings text, the rendered arrow, and the MQTT control.
- 75 Python tests pass, including HTML/static cache policy and conditional requests.
- The existing 32 layout checks and accessibility/interaction checks pass.
- Ruff, Mypy, and JavaScript syntax checks pass.

No dependency versions or persistent-data schema have changed. Use
`ghcr.io/bxjrke/patchdeck:0.6.3` and the normal upgrade procedure, then reload the
page. The `0.6` image tag tracks this patch release.
